Bejelentések

GitHub kapcsolat (publikáláshoz)

A publikáláshoz (hogy a bejelentések valóban felkerüljenek a publikus oldalra) egy GitHub Personal Access Token szükséges, amivel a böngésződ közvetlenül tud írni a repóba. A token csak ennek a böngészőnek a tárolójában (localStorage) marad — sehova máshova nem kerül, nem lesz a repó része. Ajánlott: fine-grained token, csak erre a repóra, csak „Contents: Read and write” jogosultsággal.
